Why a new site beats patching this one

  • The problems aren't in one place: 3 of 11 areas score below 70 (Conversion & trust, Speed & Core Web Vitals, Security & privacy). Fixing them one by one means touching almost every page and template.
  • The site is built on outdated foundations (an outdated CMS, heavy page-builder code). Patching old code usually costs more than building new, and the result still looks dated.
  • We found 3 security and privacy gaps. A modern build closes them by default instead of one at a time.
  • 4 conversion problems mean visitors who find you are leaving without calling or booking. A new site can be designed around turning visitors into customers.
  • Accessibility gaps create ADA lawsuit risk. A new build can meet WCAG 2.1 AA from day one.

Security & privacy · 64/100

medium

No HSTS header

The site doesn't force browsers to always use the secure connection.

What it costs you: Visitors on public Wi-Fi can be silently downgraded to an insecure connection.

medium

No Content Security Policy

Nothing limits which scripts can run on the site.

What it costs you: If a plugin or ad script is compromised, it can inject spam, redirects or card skimmers.

medium

No clickjacking protection

Any other website can load this site inside a hidden frame.

What it costs you: Attackers can trick visitors into clicking buttons on your site without knowing it.

low

Missing X-Content-Type-Options header

Browsers may guess file types, which opens the door to some script attacks.

What it costs you: A small but easy-to-close security gap.

low

Server software versions are public

The server announces exactly what it runs (x-powered-by: PHP/8.5.12).

What it costs you: Attackers use these version numbers to find known exploits for your server.

low

WordPress version is publicly visible

The page code announces 'WordPress 7.0.2'.

What it costs you: Makes it easier for automated bots to target the site.

low

Tracking runs with no cookie notice

Analytics or ad pixels load without any cookie notice or consent option.

What it costs you: A growing legal risk under state privacy laws, and Google now limits ad data without consent.
