  • The site is built on outdated foundations (retired HTML, a table-based layout, an outdated CMS, old JavaScript libraries). Patching old code usually costs more than building new, and the result still looks dated.

Security & privacy · 32/100

critical

Forms send customer data without encryption

Contact or login forms submit over plain http://.

What it costs you: Names, phone numbers and messages your customers type can be read by anyone on the network.

Affected pages (1)
https://parkslopefamilydental.com/contact.html
high

Outdated, publicly visible CMS version (WordPress 5.8.2)

The site runs an old content-management system version and advertises it in the page code.

What it costs you: Old CMS versions are the #1 way small-business sites get hacked and blacklisted by Google.

high

Outdated JavaScript libraries: jQuery 1.12.4

These versions have publicly known security vulnerabilities.

What it costs you: Known vulnerabilities in old libraries let attackers run code in your visitors' browsers.

medium

No Content Security Policy

Nothing limits which scripts can run on the site.

What it costs you: If a plugin or ad script is compromised, it can inject spam, redirects or card skimmers.

medium

No clickjacking protection

Any other website can load this site inside a hidden frame.

What it costs you: Attackers can trick visitors into clicking buttons on your site without knowing it.

medium

No privacy policy

The site collects visitor data (forms or tracking) without a privacy policy.

What it costs you: Required by Google Ads, Meta ads and privacy laws, and its absence reduces trust.

low

Missing X-Content-Type-Options header

Browsers may guess file types, which opens the door to some script attacks.

What it costs you: A small but easy-to-close security gap.

low

Server software versions are public

The server announces exactly what it runs (server: SimpleHTTP/0.6 Python/3.13.18).

What it costs you: Attackers use these version numbers to find known exploits for your server.

low

Tracking runs with no cookie notice

Analytics or ad pixels load without any cookie notice or consent option.

What it costs you: A growing legal risk under state privacy laws, and Google now limits ad data without consent.
